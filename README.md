## Planned Features

### Game Features
- Add a total game timer for each player.
- Add a per-turn timer that resets after every move.
- Display the current player's piece color in the Information Panel.
- Show player names, piece counts, timers, and match status in the Information Panel.

### Account System
- Allow users to either log in or play as a guest.
- Enable logged-in users to enter their name and the name of the second player.
- Create user profiles to store player information and game statistics.

### Statistics & Data Storage
- Store player statistics, including:
  - Games played
  - Wins
  - Losses
  - Draws
  - Total play time
  - Average turn time
  - Fastest win
  - Longest game
- Save match history with:
  - Date and time
  - Player names
  - Winner
  - Match duration


### Local Multiplayer
- Support two-player gameplay on the same device.
- Add support for dual-screen local multiplayer, allowing each player to view the game from their own screen while remaining synchronized.

### Online Multiplayer
- Enable real-time online multiplayer gameplay.
- Allow players to create or join online matches.
- Synchronize game state and moves between connected players.
- Add private game rooms with room codes for friends.
- Implement online user authentication and profiles.
- Maintain online player statistics and rankings.
- Add global leaderboards.

### Additional Features
- Add multiple board and piece themes.
- Implement AI opponents with multiple difficulty levels.
- Support saving and loading unfinished games.
- Add an achievement system with unlockable milestones and rewards.
